# 🌍 Автономна IoT Метеостанція на ESP32-C6



## 📌 Про проєкт

Цей проєкт є прикладом побудови **енергоефективної бездротової IoT-метеостанції** з низьким споживанням енергії. Пристрій зчитує показники температури, вологості та атмосферного тиску, після чого передає їх у форматі JSON через локальний MQTT-брокер до сервера Home Assistant. 



Проєкт розроблено як навчальний та практичний приклад інтеграції мікроконтролерів нової архітектури RISC-V із сучасними системами домашньої автоматизації через Docker-контейнеризацію.



---



## ⚡ Ключові особливості (Features)

* **Сучасна архітектура:** Використання чіпа **ESP32-C6** на базі енергоефективного одноядерного процесора RISC-V із підтримкою Wi-Fi 6.

* **Глибоке енергозбереження:** Реальний виміряний струм у режимі `Deep Sleep` становить **всього 500 мкА (0.5 мА)** без фізичного випаювання деталей з плати розробника.

* **Кероване живлення датчиків:** Датчики підключені до цифрового піна GPIO22. Перед засинанням мікроконтролер повністю знеструмлює сенсори та переводить шину I2C у високоімпедансний стан (High-Z). Це усуває паразитичні витоки струму та запобігає самонагріванню термометра.

* **Автономність:** Працює від блока з 4-х батарейок типу АА або ААА. Завдяки оптимізації сну пристрій здатний функціонувати багато місяців на одному комплекті живлення.

* **Локальність та безпека:** Дані передаються всередині домашньої мережі на локальний брокер Mosquitto без використання сторонніх китайських чи американських хмарних сервісів.

* **Надійний облік циклів:** Лічильник завантажень (Boot Count) зберігається в енергонезалежній RTC-пам'яті чіпа і не скидається під час глибокого сну.

## 🛠️ Схемотехніка та апаратна частина (Hardware)

Для реалізації проєкту використано такі компоненти:

1. **Мікроконтролер:** ESP32-C6-Zero Mini (ESP32-C6FH4, 4MB Flash).

2. **Модуль датчиків:** Комбінована прецизійна плата AHT20 (температура/вологість) + BMP280 (температура/тиск) з інтерфейсом I2C.

3. **Живлення:** Блок батарейок 4xAA/AAA (номінально 6V).

4. **Керування:** Тумблер ON/OFF (SPST) для повного знеструмлення під час тривалого зберігання.

5. **Діагностика:** На платі реалізовано роз'єм зі знімною перемичкою (джампером) для зручного підключення мультиметра в розрив лінії живлення задля контролю струму.



*Детальну електричну принципову схему з'єднань та перелік контактів наведено у папці `hardware/`.*

## 🏗️ Архітектура системи (Architecture)

Проєкт побудовано за дворівневою IoT-архітектурою (Клієнт ➡️ Сервер):



1. **Ендпоінт (Клієнт):** ESP32-C6 прокидається за таймером ➡️ вмикає живлення датчиків ➡️ зчитує метрики ➡️ підключається до Wi-Fi 6 ➡️ публікує JSON-пакет у топік `home/weather/metrics` ➡️ знеструмлює сенсори ➡️ засинає на 10 хвилин.

2. **Серверна частина (Raspberry Pi 5 під керуванням Raspberry Pi OS):**

&#x20;  * **MQTT Брокер Mosquitto:** Приймає пакет від клієнта і утримує його в черзі.

&#x20;  * **Docker-контейнер Home Assistant Core:** Підключений до брокера, розбирає JSON-строку за допомогою вбудованих шаблонів YAML і реєструє унікальні сутності сенсорів (`unique_id`).

3. **Інтерфейс користувача:** Офіційний мобільний додаток Home Assistant на Android відображає мінімалістичний дашборд з актуальними даними та будує плавні історичні графіки за дні й тижні.

## 📂 Структура репозиторію

* `/firmware` — Фінальний вихідний код (скетч) для Arduino IDE та файл-шаблон конфігурації мережі.

* `/hardware` — Електрична принципова схема, перелік з'єднань та фотографії макетної плати.

* `/home-assistant` — Конфігураційні рядки для файлу `configuration.yaml`.

* `/docs` — Детальні покрокові інструкції з інсталяції та налаштування Mosquitto MQTT і Docker на Raspberry Pi OS.

* `/images` — Скріншоти інтерфейсу користувача та графіків зі смартфона.
